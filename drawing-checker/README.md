# 소방도면 법령 자동 검토기 (v0.1)

제작: 김재환 (소방안전관리자 1급, 소방설비기사 전기)

PDF 소방 평면도를 넣으면 범례 기호를 자동으로 잘라 도면 전체에서 같은 기호를 찾고, 축척으로 실제 거리와 면적을 계산해 화재안전기술기준 수치와 비교합니다.

## 검토 항목
| 항목 | 기준 | 근거 |
|-|-|-|
| 발신기 수평거리 | 층 각 부분에서 25m 이하 | NFTC 203 발신기 기준 |
| 소화기 보행거리 | 소형 20m 이내 (건물 안 이동거리 근사) | NFTC 101 2.1.1.4.2 |
| 소화기 능력단위 | 용도별 1단위당 바닥면적, 내화 시 2배 | NFTC 101 표 2.1.1.2 |
| 감지기 감지면적 | 부착높이·구조·종류별 1개당 면적 | NFTC 203 표 2.4.3.5, 표 2.4.3.10.1 |
| 감지기 종류 | 부착높이별 설치 가능 종류 | NFTC 203 표 2.4.1 |
| 도서 간 불일치 | 계통도·범례 주기와 평면도 표기 대조 | 설계도서 검토 |

## 동작 방식
1. 도면 쪽을 200dpi로 그림 변환, 글자에서 축척(1/200 등) 자동 인식
2. 범례표 글자(연기감지기, 소화기, 발신기 등)를 찾아 같은 줄의 기호를 템플릿으로 추출
3. 배선·벽 같은 긴 직선을 지운 뒤 크기 0.45~1.35배, 4방향으로 기호 탐색, 점수 간격으로 진짜/가짜 경계 자동 결정
4. 벽선을 이어 건물 영역을 만들고 거리·면적 계산(발신기 반경, 소화기 이동거리, 감지기별 담당 면적)
5. report.html, annotated.png, result.json 출력

## 사용
```
pip install pymupdf opencv-python numpy scipy
python fire_drawing_checker.py 도면.pdf --page 4 --use 공장 --height 6 [--fireproof]
```

## 공개 도면 시험 결과 (2026-11-24)
나라장터 공개 허가도서 「진가리 529번지 모가영농조합 증축공사」 1층 소방설비 평면도(EF-101, 1/200)
- 소화기 8개, 연기감지기 16개, 발신기 2개 위치를 눈 검수와 같게 인식(기존 발신기 1개는 범례와 모양이 달라 '기존 발신기' 글자 위치로 추정)
- 기준 충족: 발신기 최대 23.2m(25m 이내), 소화기 이동거리 최대 16.1m(20m 이내), 능력단위 필요 12 / 설치 24
- 확인 필요: 천장 높이 미표기(6m 가정 시 감지면적 경계 4개), 계통도 '기록장치 수신반' 주기와 기존 수신반 재사용 불일치
- 결과: sample_result/report.html

## 한계 (v0.1)
- 실(방) 구분 없이 가까운 감지기로 면적을 나눈 근사, 보행거리는 내부 벽·문 미반영
- 천장 높이·구조·용도는 도면에 없으면 직접 입력
- 범례와 다른 모양으로 그린 기호는 놓칠 수 있음 → 다음 판에서 DXF(CAD) 직접 읽기, 실 경계 인식, 유도등·스프링클러 헤드 검토 추가 예정

참고용 자동 검토이며 최종 판단은 화재안전기술기준 원문과 관할 소방서 확인이 필요합니다.
