안드로이드

방법 1. 크롬에서 설치(권장, 자동 업데이트)

  1. 크롬으로 현장 수첩을 엽니다.
  2. 오른쪽 위 ⋮ 메뉴 → 앱 설치(또는 '홈 화면에 추가' → '설치')를 누릅니다.
  3. 홈 화면에 '소방 수첩' 아이콘이 생기고 주소창 없이 열립니다. 한 번 열면 지하·기계실에서도 오프라인으로 열립니다.

방법 2. 앱 파일(APK) 직접 설치

플레이스토어 등록 전 시험판입니다. 앱 이름 '소방 현장 수첩', 패키지 io.github.pefp96web.firekit, 크기 약 0.9MB. 내용은 웹 수첩과 같고(신뢰할 수 있는 웹 활동, TWA) 자료는 기기에 저장됩니다.

APK 받기 (0.9MB)

설치할 때 '출처를 알 수 없는 앱 설치 허용'을 한 번 켜야 합니다. 서명 인증서 SHA-256: 97:F9:ED:77:49:22:62:89:B5:61:01:E6:34:29:8D:17:6F:63:33:87:03:72:81:12:EC:EC:FC:2B:36:1D:2E:88 (사이트 assetlinks.json과 같음). 크롬이 설치된 기기에서 주소창 없이 열립니다.

아이폰·아이패드

  1. 사파리로 현장 수첩을 엽니다(크롬 앱은 iOS 16.4 이상에서 공유 메뉴로 가능).
  2. 아래쪽 공유 단추(□↑) → 홈 화면에 추가 → 추가.
  3. 홈 화면 아이콘으로 열면 전체 화면으로 뜨고, 한 번 열어 둔 화면은 오프라인으로 열립니다.

앱스토어 앱은 아직 없습니다(연 99달러 개발자 등록과 맥이 필요하고, 웹을 감싼 앱은 애플 심사 지침 4.2로 거절될 수 있음).

PC(크롬·엣지)

주소창 오른쪽 설치 아이콘(⊕ 또는 모니터 모양) → 설치. 시작 메뉴에서 바로 열립니다.

설치 전 알아 둘 것

  • 자료는 설치한 그 앱(그 브라우저) 안에만 저장됩니다. 크롬에서 쓰던 자료를 APK 앱으로 옮기려면 수첩 홈 → 백업 파일 받기 → 새 앱에서 불러오기.
  • 앱을 지우거나 브라우저 데이터를 지우면 자료도 지워집니다. 백업 파일을 받아 두세요.
  • 음성 메모는 기기에 따라 인터넷이 필요합니다.
